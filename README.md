# SpellStaller

A Hollow Knight mod that adds 3 charms:

* Spell Stabilizer - This makes your vengeful spirit and howling wraiths linger, allowing for some interesting movement.
* Dream Sifter - This lets you gain HP and soul off thin air.
* Gorb's Memento - Disables your ability to dive.

Known bugs:
* None of these charms are considered charms for the sake of Salubra logic
* All the charms will always cost 0
